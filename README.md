Overview

This lab demonstrates enterprise identity and access management using Microsoft Entra ID. It focuses on role-based access control (RBAC), least-privilege design, and identity monitoring commonly used in real-world Azure environments.

Business Scenario

An organization requires centralized identity management to:

Control administrative access
Delegate responsibilities by job role
Secure privileged accounts
Monitor authentication and administrative activity
This lab simulates that environment using Microsoft Entra ID.

Technologies Used
Microsoft Entra ID
Security Groups
Directory Roles (RBAC)
Sign-in Logs
Audit Logs
